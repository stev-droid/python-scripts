# ARP Poisoner / Spoofing Tool

A Python script using the `scapy` library to perform ARP cache poisoning between a target host and a network gateway. Built for educational purposes, local lab testing, and understanding network traffic interception.

## Requirements

* Python 3
* `scapy` library
* Root / Administrator privileges (required for raw socket manipulation and sending packets)

Install dependencies using:
```bash
pip install -r requirements.txt
